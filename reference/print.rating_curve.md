# Print a rating curve fit

Every fit carries `"rating_curve"` as its second class, so this one
method covers all of them.

## Usage

``` r
# S3 method for class 'rating_curve'
print(x, ...)
```

## Arguments

- x:

  A rating curve fit.

- ...:

  Ignored.

## Value

`x`, invisibly. Called for the printed output.
